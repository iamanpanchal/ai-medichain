# MediChain

## Goal
Secure healthcare record management platform.

## Users
- Patient
- Doctor
- Hospital

## Authentication
- Email/password
- JWT
- Role-based authorization

## Patient

- Upload records
- Manage access
- View AI summaries

## Doctor
- Search patients
- Request access
- View authorized records

PostgreSQL

## Backend
Node.js + Express

## Frontend
React

## AI
Python + FastAPI

## Blockchain
Ethereum-compatible network
